Academia One manual acceptance checks (Windows + MySQL)

Preparation: Back up any existing database. Verify MySQL service and database.properties.
1. Register with valid information; confirm login and profile data persist after restart.
2. Attempt duplicate email and student ID; confirm registration is rejected.
3. Attempt login with unknown email and incorrect password; confirm helpful message.
4. Stop MySQL service and attempt login; confirm database error (not invalid password).
5. Change password, log out, confirm old password fails and new password succeeds.
6. Add/edit/delete classes; test overlapping times and invalid start/end times.
7. Switch year/semester; verify schedules and study load display the correct term.
8. Add/edit/remove curriculum subjects; verify units and grade calculations.
9. Add/complete/delete tasks; restart and confirm persistence.
10. Register second student; verify first student's private data does not appear.
11. Test at 1366x768 and 1920x1080 with Windows display scaling at 100% and 125%.
12. Test Print/PDF and confirm output reflects the selected academic term.
13. Test run.bat and VS Code Run and Debug on a fresh project extraction.
